# ConstructionNoiseReduction

공사 소음 환경에서 음성 소음 저감 알고리즘과 주파수 기반 사전 필터링의 효과를 비교하고, 작업 지시·위험 경고가 얼마나 정확하게 전달되는지 평가합니다. WAV 오프라인 실험을 진행합니다.

## macOS에서 로컬 실행

저장소 폴더에서 다음 명령을 실행합니다. Apple Silicon·Intel Mac을 지원합니다.

```bash
git pull
bash scripts/dev-local.sh
```

기본 실행은 설치 파일을 받지 않습니다. 도구가 없는 첫 실행이나 의존성 변경 시에는 안내만 표시합니다. 설치를 선택하려면 `bash scripts/dev-local.sh --install`을 실행합니다. 이때만 인터넷으로 Node.js·웹 의존성을 프로젝트 안에 설치합니다.

준비된 도구로 원음 12개·소음 3개·로컬 DB를 연결하고 개발 서버를 시작합니다. 브라우저에서 `http://localhost:5173/website/`에 접속합니다. 화면 소스를 수정하면 개발 서버에서 갱신합니다. 배포 계정 설정은 필요하지 않습니다.

## 진행 방향

1. **자료 준비** — 김도연·유채원의 clean 음성 12개와 기존 단일·복합·변화 소음 3종을 사용합니다. SNR 20·10·5·0 dB로 합성할 계획입니다.
2. **소음 특성 분석** — C로 소음 전체의 FFT 수치를 저장하고 Python으로 그래프를 그립니다. 이후 주요 피크와 합성음원에서의 음성 겹침을 살펴봅니다.
3. **사전 필터링** — 분석에서 찾은 후보 대역에 필터를 적용하고 소음 억제와 음성 보존 효과를 확인합니다.
4. **알고리즘 비교** — 초기 고정형 SS·사전패턴 고정형 SS·사전패턴 갱신형 SS·Wiener·Log-MMSE를 비교하며 전처리 유무의 효과를 살펴봅니다.
5. **평가와 정리** — STOI·ESTOI와 청음평가의 단어 선택 정답률·자연스러움·소음 방해 정도를 비교하고 홈페이지에 결과를 모읍니다.

합성 계획은 12개 원음 × 소음 3종 × SNR 4단계로 144개입니다. 알고리즘 처리 범위·최종 결과물 수량·청음평가 참여 인원은 추후 확정합니다.

세부 파라미터·실험 조건·설문 내용은 해당 작업을 진행하면서 필요한 항목부터 하나씩 정합니다. 확정한 내용은 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)에 기록합니다.

## 현재 진행

실험 자료 페이지에서 작업 지시 6개·위험 경고 6개를 문장·화자와 함께 재생할 수 있습니다. 새 원음의 합성·객관 계산·청음평가 연결은 단계별로 진행합니다.

기존 소음 3개의 전체 FFT 수치와 그래프 생성 경로를 구현했습니다. 주요 피크 검출은 대기 중입니다.

청음평가는 음원당 핵심정보 4개의 객관식 단어 선택과 자연스러움·소음 방해 정도의 1~5점 평가로 구성합니다. 참가자가 각자 재생하며 다시 듣기는 횟수 제한 없이 허용합니다.
