# ConstructionNoiseReduction

공사 소음 환경에서 음성 소음 저감 알고리즘과 주파수 기반 사전 필터링의 효과를 비교하고, 작업 지시·위험 경고가 얼마나 정확하게 전달되는지 평가합니다. WAV 오프라인 실험을 진행합니다.

## macOS에서 로컬 실행

Node.js 22.23.4가 준비된 환경에서 실행합니다. Node.js 설치는 필요한 팀원이 직접 진행합니다.

```bash
cd website
npm ci
npm run dev
```

`npm ci`는 처음 실행하거나 의존성 잠금 파일이 변경됐을 때 사용합니다. 이후에는 `git pull` 후 `npm run dev`로 실행합니다.

개발 서버가 공유 음원·완료된 FFT 그래프와 로컬 DB를 준비합니다. 브라우저에서 `http://localhost:5173/website/`에 접속합니다. 배포 계정 설정은 필요하지 않습니다.

## 진행 방향

1. **자료 준비** — 김도연·유채원의 clean 음성 12개와 기존 단일·복합·변화 소음 3종을 사용합니다. SNR 20·10·5·0 dB로 합성할 계획입니다.
2. **소음 특성 분석** — C로 Welch PSD·피크·STFT·피크 추적 수치를 저장합니다. Python은 완료된 수치로 그래프를 그리고 웹은 저장 결과를 조회합니다. Noise와 Mixture를 나누어 소음 피크와 음성 겹침을 살펴봅니다.
3. **사전 필터링** — 분석에서 찾은 후보 대역에 필터를 적용하고 소음 억제와 음성 보존 효과를 확인합니다.
4. **알고리즘 비교** — 초기 고정형 SS·사전패턴 고정형 SS·사전패턴 갱신형 SS·Wiener·Log-MMSE를 비교하며 전처리 유무의 효과를 살펴봅니다.
5. **평가와 정리** — STOI·ESTOI와 청음평가의 단어 선택 정답률·자연스러움·소음 방해 정도를 비교하고 홈페이지에 결과를 모읍니다.

합성 계획은 12개 원음 × 소음 3종 × SNR 4단계로 144개입니다. 알고리즘 처리 범위·최종 결과물 수량·청음평가 참여 인원은 추후 확정합니다.

세부 파라미터·실험 조건·설문 내용은 해당 작업을 진행하면서 필요한 항목부터 하나씩 정합니다. 확정한 내용은 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)에 기록합니다.

GitHub에는 기존 활성 자료 315개와 새 고정형 SS 비교 자료 864개(Butterworth 입력 288개·SS 출력 576개), 총 1,179개 WAV와 활성 분석·설계·지표 자료를 공유합니다. 이전 회차와 미사용 처리 음원은 로컬 보관 자료로 유지합니다. 공유 범위와 검증 방법은 [CONTRIBUTING.md](CONTRIBUTING.md#공유와-문서)를 따릅니다.

## 현재 진행

‘고정형 SS 비교’(`#ss-fixed`)에 Butterworth 2종 × 감산 강도 1·5의 576개 완료 음원과 STOI·ESTOI를 연결했습니다. 한 페이지에서 네 조합의 전체 평균, 소음·입력 SNR·문장별 입력/SS 재생과 지표 비교, 공통 처리 설정·선정 근거, 전체 CSV를 확인합니다. 기존 필터 청취평가와 독립된 비교 자료이며 SS 청취평가 응답은 아직 포함하지 않습니다.

실험 자료 페이지에서 작업 지시 6개·위험 경고 6개를 문장·화자와 함께 재생할 수 있습니다. 합성음 144개와 대응 기준음 12개를 등록하고 실제 SNR·형식·파일 지문을 검증했습니다. 필터링 전후 STOI·ESTOI를 계산해 별도 분석 화면에 연결했으며, 후속 알고리즘의 새 웹 카탈로그·객관 계산·청음평가 연결은 후속 작업입니다. 배치 조건은 PROJECT_CONTEXT를 따릅니다.

기존 전체 C FFT를 보존하고, Welch·피크·시간별 피크 추적을 C 계산 경로로 통합했습니다. Noise·Mixture 분석은 각각 3개 세부 화면에서 완료된 수치·PNG를 읽으며 대응 피크·궤적은 Mixture 상세 항목에서 조회합니다. ‘사전 필터링’에서는 무처리 합성음원/Butterworth 처리 합성음원과 입력 SNR을 선택해 하나의 표로 들을 수 있습니다. 표의 세로는 음원 12개, 가로는 소음 3종이며 칸의 버튼으로 재생·일시정지합니다. 바로 아래 ‘필터링 결과 분석’에서 같은 구조로 STOI·ESTOI의 무처리·처리 후·변화량을 비교합니다. BPF 144조건의 실제 지표와 별도 5그룹 청음평가의 참여·응답 수집 화면을 연결했습니다. 기존 EQ 결과와 원본도 보존합니다. 실행 방법은 CONTRIBUTING, 설계·청음 레벨·처리·평가 자료 관계는 PROJECT_CONTEXT를 따릅니다.

‘필터링 청음평가’에서 그룹별 참여 링크 5개와 QR을 제공합니다. 각 참가자는 배정된 그룹의 같은 조건 무처리→Butterworth 처리 6쌍·12개를 직접 재생하고, 핵심정보 4문항과 자연스러움·소음 방해 정도를 1~5점으로 평가합니다. 다시 듣기는 제한하지 않으며 같은 브라우저에서 이어서 참여할 수 있습니다. 결과 화면에는 그룹별 완료 응답의 전후 평균과 응답 수를 표시합니다.
