04 / OBJECTIVE METRIC ANALYSIS

STOI ESTOI 지표 분석

같은 소음·문장·SNR에서 처리 전후의 STOI·ESTOI와 개선량을 비교합니다.

선택한 처리 방식과 무처리의 같은 소음·문장·SNR을 대응시킵니다. 각 점의 n은 평균에 사용한 대응 음원 수입니다.

STOI·ESTOI 지표를 읽는 방법
STOI
깨끗한 기준 음성과 비교한 음성 명료도 예측값입니다. 같은 조건에서 처리 후 값이 높아지면 이해하기 쉬운 음성으로 예측합니다.
ESTOI
시간에 따라 강도가 변하는 소음에서의 명료도 예측을 확장한 지표입니다. 각 지표의 무처리 대비 개선량을 확인합니다.

ΔSTOI·ΔESTOI는 처리 후 값에서 같은 조건의 무처리 값을 뺀 값입니다. 양수는 지표 상승, 음수는 하락이며, 평균에 사용한 대응 음원 수 n을 함께 확인합니다.

실제 청음 정답률·5단계 평가와의 관계는 지표청음 비교에서 확인합니다.

연구 근거는 STOI 연구와 ESTOI 연구에서 확인할 수 있습니다.

  1. 회차 만들기평가 음원·재생 순서 선택
  2. QR 공유참가자 접속·익명 ID 발급
  3. 음원 재생·응답 시작객관식 3문항·5단계 2항목

QR 질문지와 수동 입력으로 수집한 정답률·5단계 평가를 음원별로 집계하고 원응답을 확인합니다.

접수된 QR·수동 응답을 2초 간격으로 확인합니다. 기본 표는 응답이 있는 전체 방식을 표시합니다. 평가 진행과 응답 입력은 청음평가에서 관리합니다.

결과를 볼 처리 방식

음원별 이해도 · 핵심정보 정답률

정답 수 / 전체 문항 수

이해도는 핵심정보 정답률(%)로 표시합니다. 같은 채점 기준의 응답만 합산하며, 채점 전·기준 혼재 상태와 실제 0%를 구분합니다.

음원별 5단계 테스트 결과

평균 · 응답 수

소음 방해·자연스러움 평균을 각각 표시합니다. 5단계 척도는 0 · 2.5 · 5 · 7.5 · 10이며, 높을수록 소음 방해가 적고 자연스럽습니다. 칸을 누르면 선택 음원의 누적 결과에서 5단계 응답 분포를 확인할 수 있습니다.

저장한 원응답

이해도는 핵심정보 정답률이며, 소음 방해·자연스러움은 각 평가자의 원점수입니다.

QR 하나씩 선택

삭제할 QR 회차를 선택하세요. 삭제하면 해당 QR과 진행자 링크는 사용할 수 없고, 그 회차의 응답 전체가 결과표·그래프·CSV 집계에서 제외됩니다. 회차와 원응답은 삭제 기록과 함께 전체 JSON 백업에 보존됩니다.

QR 회차 하나를 선택하면 삭제할 범위를 확인할 수 있습니다.

07 / METRICS AND LISTENING COMPARISON

지표청음 비교

같은 음원의 실측 지표와 정답률·5단계 평가를 나란히 확인하고 관계를 시각화합니다.

STOI와 청음 평가

ESTOI와 청음 평가

지표와 청음결과를 비교하는 방법

각 점은 같은 음원 1개입니다. 가로축은 STOI 또는 ESTOI, 세로축은 선택한 핵심정보 정답률(%) 또는 5단계 평가 평균(0~10)입니다.

이해도 · 핵심정보 정답률
같은 채점 기준의 정답 수 합계 ÷ 전체 문항 수 합계입니다. STOI·ESTOI와 비교하는 주 분석 지표이며, 필요한 정보를 실제로 맞혔는지 보여줍니다.
5단계 평가
소음 방해·자연스러움 평균을 각각 보조 분석합니다. 높을수록 소음 방해가 적고 자연스럽습니다. 평가자별 원점수는 보관합니다.

상관분석의 n은 대응 음원 수이며 응답자 수가 아닙니다. SNR별 평균 4개로 합치지 않고 같은 개별 음원의 지표와 청음 결과를 연결합니다.

Spearman ρ가 +1에 가까우면 지표가 높은 음원에서 청음 평가도 높은 경향을 보입니다. 0에 가까우면 단조로운 순위 관계가 약하고, −1에 가까우면 반대 방향의 경향을 보입니다. 대응 음원 수 n과 소음·SNR별 분포를 함께 확인합니다. 선정 문장 3개를 반복한 자료의 탐색적 분석입니다.

데이터 연결과 백업

음원 경로·객관 지표를 연결하고 청음 응답을 백업합니다.

01 / 로컬 음원 폴더

CNR 프로젝트의 data/·outputs/ 폴더에 WAV를 넣고 사이트를 다시 배포합니다. 배포 빌드가 실제 파일과 경로를 수집해 재생 목록에 반영합니다.

data/clean/instruction_01.wav
data/noise/single.wav
data/mixed/single/snr20/instruction_01.wav
outputs/ss_pattern_fixed/single/snr20/instruction_01.wav

파일을 교체하거나 삭제한 내용은 다음 배포에 반영됩니다. 다른 파일명은 data/metadata/dataset.json 또는 아래 경로 JSON으로 연결하세요. WAV는 파일당 25 MiB까지 배포에 포함할 수 있습니다.

02 / STOI · ESTOI

Python으로 계산한 STOI·ESTOI 결과 CSV·JSON을 서버에 업로드합니다.

sample_id,stoi,estoi
metrics/results/stoi_estoi.json

실제 계산한 지표 파일을 가져오면 서버에 저장됩니다.

03 / 서버 데이터 백업

지표·경로 설정·수동 응답과 QR 회차·질문표·원응답을 JSON으로 보관하고 복원합니다.

복원하면 서버의 연구 데이터를 교체합니다. 음원 파일은 백업에 포함되지 않습니다. 내보낸 JSON으로 원응답을 별도 보관하세요.
