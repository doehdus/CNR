D1에 응답·지표·경로, R2에 WAV를 보관한다. 다섯 메뉴, 네 처리 방식 표, 즉시 정답률·5단계 집계, 객관 지표 비교, 인쇄/PDF와 CSV/JSON을 구현한다. 아래 로컬 구현 설명은 이전 개발 이력이다. 현재 기준은 [PROJECT_CONTEXT](../PROJECT_CONTEXT.md)와 [사이트 안내](../site/README.md)를 따른다.

## 4. 결정 및 변경 이력

이전 발표용 6페이지 구성·1초 소음 시연 작업은 현재 요구사항에서 제외했다. 이전 제안의 작업 지시 3개+경고 2개, 15개 입력·60개 비교 음원 등 다른 설계 수치는 현재 계획에 적용하지 않는다.

### 2026-11-12 진행 확인과 최종 원음 선정

처음 두 사람의 녹음 총 6개 보유가 보고되었으며 이후 사용자가 **유채원의 지시 2개와 김도연의 경고 1개, 총 3개를 평가 대상으로 선정**했다. 전체 6개를 소음·SNR과 조합하는 가정은 현재 설계에서 제외했다.

현재 혼합 조건은 36개다. 초기 고정형 SS만 사용하면 출력 36개·무처리 포함 평가 후보 72개, SS 3종이면 출력 108개·평가 후보 144개, 추가 1종 포함 시 출력 144개·평가 후보 180개다. 실제 인수·검증 개수와는 구분한다.

사용자가 홈페이지·내부 설정의 로컬 구현을 요청하여 현재 `website/`에 구현했다. 브라우저 저장·JSON 백업은 현재 로컬 구현 선택이며 실제 자료 인수 후 검증은 별도로 남긴다.
