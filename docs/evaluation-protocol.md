# 평가 프로토콜

갱신: 2026-11-15. 상위 기준은 [프로젝트 확정 사항](../PROJECT_CONTEXT.md), 운영 절차는 [사이트 안내](../site/README.md)를 따른다.

## 1. 평가 대상과 식별

선정 원음은 유채원의 작업 지시 1·2와 김도연의 위험 경고 1, 총 3개다. 문장에 고정된 녹음자를 바꾸지 않는다. 같은 문장·소음·SNR의 무처리와 처리 음원은 공통 조건으로 대응시키고, 지표와 사람 응답은 같은 `sample_id`로 연결한다.

3문장 × 소음 3종 × SNR 4단계로 혼합 조건은 36개다. 무처리 36개와 네 처리 방식 144개를 합한 평가 후보는 최대 180개다. 현재 로컬의 계산 대상은 무처리 36개·초기 고정형 SS 36개다. 전체 후보 수와 평가자 1명의 배정·실제 수집 건수를 구분한다.

입력 준비·형식·정렬·SNR 검증은 [실험 프로토콜](experiment-protocol.md)을 따른다.

## 2. 객관 평가와 결과 전달

같은 문장의 깨끗한 기준 음성과 무처리 또는 처리 음성을 비교해 STOI·ESTOI를 각각 계산한다. 개선량은 같은 소음·SNR·문장의 무처리와 대응시킨다.

- `ΔSTOI = 처리 STOI - 무처리 STOI`
- `ΔESTOI = 처리 ESTOI - 무처리 ESTOI`
- 점수 0은 실제 값으로 보존하고 누락·계산 실패와 구분한다.
- STOI·ESTOI를 실제 단어 정답률(%)로 표시하거나 5단계 점수와 합산하지 않는다.

계산 코드는 `metrics/calculate_metrics.py`, 완료 데이터는 `results/metrics/stoi_estoi.json`과 `results/metrics/stoi_estoi.csv`다. 기본 16 kHz 리샘플링, ±0.5초 범위의 고정 지연 보정, 공통 구간 선택 후 실제 점수를 계산하며 입력 경로·SHA-256·도구 버전·계산 구간·정렬 내역을 보존한다.

`calculate-metrics.cmd`와 `build-site.cmd`는 각각 계산과 홈페이지 반영·빌드의 진입점이다. 웹사이트는 완료 JSON을 읽어 표·개선량·그래프를 만들며 Python 계산기를 실행하지 않는다. 지표 전달에는 DB가 필요하지 않다. 변경된 WAV·경로·임시 음원에 이전 점수를 연결하지 않는다. [계산 안내](../metrics/README.md)와 [결과 데이터 계약](../results/README.md)을 따른다.

## 3. QR 회차별 청음평가

사람 평가는 홈페이지의 QR 질문지로 수집한다. 연구자는 회차별 평가 음원과 순서를 정해 참가자 공통 QR과 진행자 전용 링크를 만든다. 같은 장소·장비에서 여러 명이 함께 듣고, 연구자가 재생·응답 시작·다음 음원·종료를 제어한다.

1. 연결된 평가 음원을 선택하고 회차 이름과 순서를 정한다. 기본 순서 섞기 또는 직접 순서 조정을 사용한다.
2. 참가자는 QR에서 평가 참가를 누른다. 익명 ID를 발급하며 같은 브라우저의 재접속을 지원한다.
3. 연구자가 음원을 재생한 뒤 응답을 연다. 참가자는 객관식 3문항과 소음 방해·자연스러움 두 항목의 5단계 평가를 제출한다. 이해도는 핵심정보 정답률로 측정한다.
4. 연구자가 제출 인원을 확인하고 다음 음원을 진행한다. 화면은 2초 간격으로 진행·응답을 확인한다.
5. 수집 결과는 기존 음원 ID에 연결해 청음결과표와 지표청음 비교에 반영한다.

회차 생성 시 질문표·음원 순서·입력 파일 지문을 고정한다. 참가자 응답 화면에는 처리 방식·객관 점수·정답·다른 사람의 점수를 공개하지 않는다. 진행 링크는 연구자만 보관하고 공개 문서·GitHub에 기록하지 않는다.

## 4. 핵심 정보 정답률

현재 QR 채점 기준은 `qr-mc-v1`이다. 문장마다 객관식 3문항이며 문항당 1점, 음원당 총 3점이다.

| 문장 | 세 문항의 정답 기준 |
| --- | --- |
| 작업 지시 1 | 장비 이동 · 뒤로 · 2미터 |
| 작업 지시 2 | 각재 · 3개 · 오른쪽 적재장 |
| 위험 경고 1 | 정지 · 장비 뒤 · 사람 |

각 문항은 일반 보기 네 개와 모르겠음을 제공한다. 일반 보기의 순서는 참가자별로 섞으며 재접속 시 유지한다. 서버가 답변과 채점 기준으로 정답 수를 산출한다. 클라이언트가 보낸 임의 점수를 정답 수로 신뢰하지 않는다.

모르겠음과 오답은 0점이다. 미제출은 응답 행을 임의로 만들지 않는다. 해당 기준에는 부분 점수를 적용하지 않는다. 수동 응답은 채점 기준 버전과 정수 정답 수·전체 문항 수가 모두 있어야 정답률을 산출하며, 같은 기준의 정답 수 합계 / 전체 문항 수 합계로 집계한다. 서로 다른 기준은 합산하지 않는다.

## 5. 5단계 청취 평가

소음 방해·자연스러움을 각각 `0 / 2.5 / 5 / 7.5 / 10`으로 받는다. 두 항목 모두 높은 점수가 좋은 방향이다. 별도의 5단계 이해도 문항은 사용하지 않으며 이해도는 4절의 핵심정보 정답률로 대체한다.

| 점수 | 소음 방해 정도 | 음성 자연스러움 |
| ---: | --- | --- |
| 0 | 음성을 거의 전부 가림 | 심한 왜곡과 끊김 |
| 2.5 | 말을 자주 가림 | 왜곡이 이해를 방해 |
| 5 | 집중해야 들림 | 기계음·떨림이 뚜렷 |
| 7.5 | 방해가 적음 | 약간의 왜곡 |
| 10 | 이해를 거의 방해하지 않음 | 뚜렷한 왜곡·끊김 없음 |

두 항목을 별도 저장·집계한다. 임의로 합산해 명료도 점수로 사용하지 않는다. 정답률은 %로, 소음 방해·자연스러움은 5단계 원점수와 평균으로 표시한다. 선택 음원에서 응답 수와 단계별 응답 분포를 확인한다.

## 6. 저장·수동 입력·백업

QR 회차·참가자·원응답·진행 상태는 서버 D1에 저장한다. 브라우저의 참가·진행 토큰 보관은 재접속 수단이며 연구 원응답 저장소를 대신하지 않는다. 연구자는 수동 응답 입력과 CSV·JSON 가져오기도 사용할 수 있다. 입력 중 계산은 미저장 미리보기이며 서버 저장 성공 후 누적 집계에 반영한다.

ID·중복·누락·점수 범위·채점 기준을 검증한 뒤 저장한다. 같은 참가자·음원 조합의 중복을 거부하며 QR 재전송은 같은 응답으로 처리한다. 자료·진행 버전이 달라진 요청은 덮어쓰지 않는다. 저장한 QR 응답을 수동 자료에 중복으로 가져오지 않는다.

JSON 전체 백업 v2는 연구 상태와 QR 회차·참가자·원답변·질문표·삭제 시각을 포함한다. 복원 전 현재 자료를 백업하며, 복원은 서버 버전 검사와 트랜잭션을 적용한다. v1 복원은 현재 QR 자료를 유지하면서 수동 연구 자료를 복원한다. 원응답 CSV에는 QR·수동 응답을 함께 내보낸다.

2026-11-15 사용자 결정에 따라 기존 5단계 체감 이해도 값은 수동·QR 저장 자료에서 삭제한다. 정오답과 소음 방해·자연스러움 원점수는 보존한다. 예전 CSV·JSON·백업의 `understanding` 필드는 가져오기·복원 시 제거하며 새 설문이나 집계에 다시 사용하지 않는다. 기존에 별도 다운로드한 백업 파일 자체는 변경하지 않는다.

청음결과표의 QR 회차 삭제는 해당 회차 전체를 집계에서 제외하고 참가자·진행 링크를 사용할 수 없게 한다. 다른 회차·수동 응답은 유지하며 삭제한 회차의 원자료는 전체 백업에 남긴다. 개별 응답 선택 삭제 UI·API는 제공하지 않는다.

운영 중 원자료는 D1, 별도 전달받은 평가 자료는 `evaluations/`, 내보내기·백업은 `exports/`·`backups/`에 비공개로 보관한다. 웹 저장이 프로젝트 원자료 폴더에 자동 기록되는 것은 아니다.

## 7. 집계와 Spearman 분석

음원별 유효 응답 수·소음 방해 및 자연스러움의 평균과 분포·동일 채점 기준의 정답률을 구한다. 같은 소음·SNR·문장의 처리 전후만 대응시키고, 대응 지표가 없는 음원은 해당 분석에서 제외한다. 개별 응답은 별도로 보관하며, SNR별 평균 네 개로 합쳐 상관을 구하지 않는다.

주 분석은 STOI·ESTOI 각각과 핵심정보 정답률로 측정한 이해도의 관계다. 소음 방해·자연스러움 평균은 각각 보조 분석으로 선택한다. 정답률 비교는 채점 기준을 원응답에 먼저 적용한 뒤 음원별 집계한다. 상관의 n은 대응 음원 수이며 응답자 수와 구분한다. 분석 JSON은 version 2에 분석 단위와 주 분석 항목을 함께 기록한다.

Spearman은 동점 평균 순위를 사용한다. 대응 음원 수가 2개 미만이거나 값에 변동이 없으면 계산 불가로 표시한다. 계산 가능 여부가 통계적 충분성을 뜻하지 않는다. 분석 대상 음원·소음·SNR·처리 방식·유효 응답 수를 함께 기록한다.

## 8. 실제 연구에서 남은 확인

- 참여 인원·배정, 재생 장치·볼륨·횟수·휴식과 청취 환경
- 세 문장 반복에 따른 내용 기억 효과, 순서·반복 측정의 통제
- 목표 SNR·클리핑·소음 출처와 처리 파라미터의 실측 검증
- 실제 응답 수집·원자료 보관·분석 범위와 결과 확정
- 후속 SS 방식·추가 알고리즘의 구현과 같은 입력에 대한 결과 인수

현재 확인된 객관 지표 72개와 도구의 구현·자동 검증을 사람 평가·연구 결론 완료와 구분한다. 실제 청음 응답 건수는 운영 D1에서 확인한다. 제한된 문장·녹음자·평가자 범위의 결과를 일반적인 성능이나 지표 우열로 단정하지 않는다.
