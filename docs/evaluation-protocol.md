# 평가 프로토콜

## 2026-11-14 QR 수집 확정 기준

사람 평가는 현재 홈페이지의 QR 질문지로 수집한다. 연구자가 회차별 평가 음원과 순서를 정해 공통 QR 하나를 발급한다. 같은 장소·장비에서 여러 명이 동시에 듣고, 연구자가 음원 재생·응답 시작·다음 문항을 제어한다. 참가자는 익명 ID로 접속하며 음원마다 답변을 저장한다.

핵심정보 정답률은 문장별 객관식 3문항·각 1점으로 자동채점한다. 작업 지시 1은 장비 이동·뒤로·2미터, 작업 지시 2는 각재·3개·오른쪽 적재장, 위험 경고 1은 정지·장비 뒤·사람을 정답으로 한다. 각 문항은 모르겠음을 포함하며, 기준 버전은 `qr-mc-v1`이다. 선택한 모든 음원에서 이 기준을 적용한다.

5단계 평가의 이해도·소음 방해·자연스러움과 0/2.5/5/7.5/10 척도는 유지한다. QR 원응답을 기존 음원 ID로 연결해 정답률·평균과 STOI·ESTOI 관계를 분석한다. QR 회차·참가자·원응답은 D1에 저장하고 JSON 백업 v2에 포함한다. 기존 수동 입력도 지원한다. 아래 과거 종이 수집 및 채점 미확정 설명은 이 결정으로 대체한다.

> 2026-11-12 최신 구현: 종이 응답 입력·정답률·5단계 집계는 배포 사이트의 서버 D1에 저장한다. WAV는 R2에 보관하며, 브라우저 localStorage를 원자료 저장소로 사용하지 않는다. 주 분석은 이해도이며, 홈페이지에서 정답률·소음 방해·자연스러움도 개별 선택해 탐색 비교할 수 있다. 정답률은 동일 채점 기준만 비교한다. 과거 로컬 구현·브라우저 저장 설명은 이 변경으로 대체된다. 사용 방법은 [site/README.md](../site/README.md)를 따른다.

상위 기준: [프로젝트 확정 사항](../PROJECT_CONTEXT.md)

**확정 사항:** 사람 평가는 종이로 실시하며, 5단계 청취 평가와 핵심 정보 정답률을 모두 사용한다. 연구자가 응답을 웹사이트에 입력하거나 파일로 불러와 객관 지표와 비교·분석한다.

## 1. 평가 대상과 식별

동일 녹음자·문장·소음 유형·입력 SNR의 무처리 음원과 각 알고리즘 출력에 공통 조건 정보를 부여하고, 개별 평가 음원을 식별할 수 있게 관리한다. 선정 원음은 유채원의 작업 지시 1·2와 김도연의 위험 경고 1, 총 3개다. 문장에 고정된 녹음자를 바꿔 연결하지 않는다. 객관 지표와 사람 응답은 반드시 같은 음원 식별자로 연결한다.

선정 원음 3개 × 소음 3종 × SNR 4단계로 혼합 조건 36개다. 초기 고정형 단계의 평가 후보는 무처리 36개와 처리 출력 36개, 총 72개다. SS 3종이면 144개, 추가 1종까지 구현하면 180개다. 실제 인수·등록·검증 수와 목표 수를 구분한다. 이는 전체 후보 수이며 평가자 1명의 필수 청취 횟수가 아니다. 평가 참여 인원과 배정은 미확정이다.

입력·기준 음성·출력의 준비와 정렬은 [실험 프로토콜](experiment-protocol.md)을 따른다.

## 2. 객관 평가: STOI·ESTOI

- 같은 녹음자·문장의 시간 정렬된 깨끗한 기준 음성과 무처리 또는 처리 음성을 비교한다.
- 음원별 STOI·ESTOI를 계산하고 같은 조건의 무처리 점수도 보관한다.
- 개선량은 `ΔSTOI = 처리 STOI - 무처리 STOI`, `ΔESTOI = 처리 ESTOI - 무처리 ESTOI`로 기록한다.
- STOI·ESTOI를 실제 단어 정답률(%)로 표시하지 않는다.
- ESTOI가 모든 조건에서 더 우수하다고 사전에 가정하지 않는다.

계산 위치는 `metrics/calculate_metrics.py`, 결과 위치는 `metrics/results/stoi_estoi.csv`와 `metrics/results/stoi_estoi.json`이다. 음원 식별자, 조건, 점수, 무처리 대비 개선량, 계산 도구·버전과 조건을 기록한다.

WAV 계산은 두 신호를 기본 16 kHz로 리샘플링한 뒤 ±0.5초 범위의 교차상관으로 고정 지연을 추정하고 겹치는 구간을 평가한다. 결과에는 원본 샘플레이트, 실제 계산 구간의 샘플레이트·길이, 지연, 앞·뒤 제외량, 정렬 후 상관계수와 원본 파일 SHA-256을 기록한다. 세부 호출과 옵션은 [계산 안내](../metrics/README.md)를 따른다.

기준 음성이나 입력이 없거나 정렬 검증을 통과하지 못한 경우 실제 점수로 취급하지 않는다. 누락·계산 실패와 점수 0을 구분하며, 임의 수치를 채우지 않는다.

## 3. 종이 5단계 청취 평가

평가자는 음원을 듣고 종이에 다음 3항목을 각각 응답한다. 기존 계획의 5단계 점수 체계 `0 / 2.5 / 5 / 7.5 / 10`과 설명을 기준안으로 유지한다.

| 점수 | 지시 및 경고 이해도 | 소음 방해 정도 | 음성 자연스러움 |
| ---: | --- | --- | --- |
| 0 | 거의 이해하지 못함 | 음성을 거의 전부 가림 | 심한 왜곡과 끊김 |
| 2.5 | 일부 단어만 이해 | 말을 자주 가림 | 왜곡이 이해를 방해 |
| 5 | 의미는 알지만 핵심 누락 | 집중해야 들림 | 기계음·떨림이 뚜렷 |
| 7.5 | 대부분 이해 | 방해가 적음 | 약간의 왜곡 |
| 10 | 핵심 정보 모두 이해 | 이해를 거의 방해하지 않음 | 뚜렷한 왜곡·끊김 없음 |

소음 방해 항목도 높은 점수일수록 방해가 적은 방향이다. 3항목은 개별로 저장·집계하며, 임의로 합산해 명료도 점수로 사용하지 않는다.

기존 권장사항인 처리 방식명 숨기기와 재생 순서 무작위 배정을 유지한다. 실제 음원 배정·재생 횟수·청취 환경·문장 기억 효과 통제 방법은 본 평가 전에 확정한다.

## 4. 핵심 정보 정답률

5단계 평가와 별도로, 청취자가 문장의 핵심 정보를 얼마나 정확히 이해했는지 종이 응답으로 확인한다. 이 지표의 **사용 여부는 확정**되었으며 채점 세부 규칙은 미확정이다.

다음은 기존 문장에서 채점 문항을 설계할 때 참고할 후보이며, 최종 문항·정답표가 아니다.

| 문장 | 핵심 정보 후보 |
| --- | --- |
| 작업 지시 1 | 장비 이동, 뒤쪽 방향, 2미터 |
| 작업 지시 2 | 각재, 3개, 오른쪽 적재장 |
| 위험 경고 1 | 정지, 장비 뒤, 사람 존재 |

문장별 문항, 정답과 허용 표현, 배점, 부분 정답, 무응답 처리 및 정답률 분모를 확정해야 한다. 확정 전에는 후보를 임의의 정답표로 사용하거나 정답률을 계산하지 않는다. 종이 원응답과 채점 결과를 함께 보관하고 적용한 양식·채점 기준을 구분할 수 있게 한다.

## 5. 수집·입력·보관 흐름

1. 평가 양식과 음원별 배정표를 준비한다.
2. 익명 평가자 식별자와 음원 식별자가 대응되도록 종이로 두 평가를 수집한다.
3. 연구자가 응답을 웹사이트에 입력하거나 파일로 불러온다.
4. 음원 대응, 중복, 누락, 점수 범위와 채점 기준을 확인한다.
5. 음원별·조건별 결과를 집계하고 객관 지표와 연결한다.
6. 원자료와 분석 결과를 구분하여 보관한다.

| 구분 | 보관 위치 |
| --- | --- |
| 종이 평가 양식·정답 및 채점 기준 | `evaluations/paper-forms/` |
| 입력·가져온 개별 원응답 및 채점 자료 | `evaluations/raw/` |
| 집계·상관분석 결과 | `evaluations/analysis/` |

사람 응답에는 익명 평가자 식별자, 음원 식별자, 양식 정보, 3항목 점수, 핵심 정보 원응답·채점 결과가 필요하다. 현재 로컬 구현은 CSV·JSON 가져오기, 브라우저 localStorage 저장과 전체 JSON 백업·복원을 지원한다. 프로젝트 원자료 파일에 자동 기록하지 않는다. 같은 평가자·음원 조합의 중복 저장은 거부하고 원자료 확인 후 삭제·재입력으로 정정한다. 별도의 응답 수정 이력 기능은 아직 없다. 청취자의 웹 직접 평가·제출은 이번 수집 방식에 포함하지 않는다.

## 6. 집계와 Spearman 분석

음원별로 유효 응답 수와 3항목의 평균을 구한다. 핵심 정보 정답률은 채점 규칙을 확정한 뒤 별도로 집계한다. 누락된 응답을 임의로 0점 처리하지 않는다.

주 분석은 같은 음원 단위로 다음 두 쌍을 대응시킨다.

- STOI ↔ 사람의 지시 및 경고 이해도 평균
- ESTOI ↔ 사람의 지시 및 경고 이해도 평균

두 관계에 대해 Spearman 순위상관계수를 계산한다. 분석에 사용한 음원 수, 음원 목록·조건 범위와 유효 응답 수를 함께 기록한다. 조건별 분석 시 소음 유형·SNR별 포함 범위도 구분한다.

음성 자연스러움과 소음 방해 점수는 별도로 제시한다. 핵심 정보 정답률을 추가 상관분석에 사용할지는 채점 규칙과 함께 별도 확정하며, 주 분석을 임의로 대체하지 않는다.

대응 음원이 없거나 자료가 부족한 경우 결과를 산출한 것처럼 표시하지 않는다. 단일 응답이나 선정 문장 3개를 반복한 제한된 표본으로 지표의 우열이나 일반적 성능을 단정하지 않는다.

## 7. 본 평가 전 남은 결정

- 참여 인원, 음원 배정, 재생 횟수와 청취 환경
- 핵심 정보 문항·정답·허용 표현·배점·무응답 처리
- 종이 양식과 최종 채점 세부 규칙
- 원자료 백업·보관 운영과 필요 시 서버 영구 저장 범위
- 객관 지표 계산 도구·버전과 실행 검증

현재 종이 양식·실제 원응답·실측 객관 점수·연구 분석 결과는 없다. 구현된 입력·집계·분석 도구와 연구 평가 완료를 구분한다.

## 8. 로컬 구현의 현재 처리 규칙

- 입력·가져오기는 파일 전체를 검증한 뒤 반영한다. 오류가 있는 일부 행만 저장하지 않는다.
- 0점은 실제 점수로 보존하며 누락과 구분한다. 무처리·처리 어느 쪽이든 해당 지표가 없으면 개선량을 계산하지 않는다.
- 현재 핵심 정보 연결 기능은 채점표 버전과 정수 정답 수·전체 문항 수를 모두 요구한다. 동일 버전의 채점 응답은 정답 수 합계 / 전체 문항 수 합계로 집계한다. 서로 다른 버전은 합산하지 않고 채점 응답 수도 표시한다.
- 위 정수 문항 방식은 확정된 채점표를 연결하기 위한 현재 구현이다. 부분 정답 배점 등 최종 연구 규칙이 확정되면 필요에 따라 조정한다. 채점표 미확정 상태에서는 원응답만 저장한다.
- Spearman은 동점 평균 순위를 사용한다. 지표가 없는 음원은 해당 지표 분석에서 제외한다. 대응 음원이 2개 미만이거나 값의 변동이 없으면 계산 불가로 표시한다. 계산 가능 여부가 통계적 충분성을 뜻하지 않는다.
- 현재 분석은 이해도 평균을 주 대상으로 하며 핵심 정보 정답률·자연스러움·소음 점수를 합산하지 않는다.

파일 형식과 백업 절차는 [홈페이지 사용 안내](../site/README.md)를 따른다. 자동 테스트와 HTTP 검증은 통과했으며 실제 음원·응답 인수 후 재생·연결 검증이 필요하다.
